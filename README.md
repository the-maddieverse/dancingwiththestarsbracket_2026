# dancingwiththestarsbracket_2026

Public, online-ready **Dancing with the Stars 2026 elimination bracket**.

## What is included
- `index.html`: a complete static bracket app
- Inline editing for couple names
- Elimination toggles (`Out` / `Undo`) that advance winners automatically
- Auto-save in browser `localStorage`

## Run locally
Open `index.html` directly in your browser, or serve it:

```bash
cd /home/runner/work/dancingwiththestarsbracket_2026/dancingwiththestarsbracket_2026
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish publicly
This repository can be published online via **GitHub Pages**:
1. Go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select your branch and `/ (root)` folder.
4. Save — GitHub will publish `index.html` as a public website.
